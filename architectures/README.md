# Architectures

System designs: each one explains **what** was designed, **why** each choice was made, and
**what it costs**. Start every new design from
[templates/ARCHITECTURE_TEMPLATE.md](../templates/ARCHITECTURE_TEMPLATE.md).

Each design lives in its own folder, `NN-system-name`, numbered in order, for example:

```
architectures/
└── 01-design-name/
    ├── README.md
    └── diagram.png
```
